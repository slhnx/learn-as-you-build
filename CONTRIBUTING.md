# Contributing

Thanks for helping improve Learn As You Build.

## How to contribute

1. Open an issue describing the problem or proposed improvement.
2. Include a reproducible example when reporting unexpected behavior.
3. Explain which agent and version you tested.
4. For pull requests, describe the change and how you verified it.
5. Keep instructions concise and avoid adding unnecessary interaction overhead.

## Testing checklist

- Does the skill activate for relevant coding tasks?
- Does it avoid interrupting trivial changes?
- Are learning notes accurate and free of duplicate entries?
- Are quizzes based on concepts actually encountered?
- Does it clearly distinguish verified behavior from assumptions?

Please do not include private source code, credentials, API keys, or personal information in examples.

## Scope

This project focuses on helping developers understand code generated with AI. Features should support that goal without turning every coding task into a lengthy tutorial.
